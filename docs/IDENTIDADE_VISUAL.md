# Identidade visual

## Sanctum Veritatis

Preto mineral, grafite, aço e branco envelhecido formam a base. Âmbar orienta atenção; vermelho escuro comunica contenção; azul frio identifica telemetria; verde discreto confirma integridade.

## Tipografia

- Display institucional: família condensada para títulos e operações.
- Corpo: família neutra de sistema para leitura longa.
- Técnica: monoespaçada para códigos, datas, estados e metadados.

## Linguagem formal

O símbolo `SV` em losango funciona como marca provisória construída em CSS. A interface evita iconografia decorativa e privilegia códigos, classificações, linhas de integridade e sinais operacionais.

## Variações planejadas

Setentrional usará azul profundo e sinais marítimos; Sintech, azul técnico; Conselho Escarlate, marfim e vermelho institucional; Aurora, violeta frio; NCM, verde militar e papel documental.
