# Testes

Execute `npm.cmd run validate`. O comando verifica sintaxe de scripts críticos, autorização/sessão, isolamento de dados, Sintech, RedLotus, retratos, itens e Arquivo Central e então reconstrói os artefatos.

Em 20/07/2026, todos os testes Node passaram. Ainda faltam Playwright/Cypress, teste visual nos viewports 320–1920 px, leitores de tela, navegadores cruzados, Lighthouse e teste de implantação. Resultados não executados não devem ser apresentados como aprovados.
