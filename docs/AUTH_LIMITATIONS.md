# Limitações do modo público

O repositório público não contém senhas nem hashes de senha. A tela de entrada abre apenas uma sessão demonstrativa local para perfis narrativos conhecidos.

- Não há autenticação de servidor ou confidencialidade.
- Metadados e conteúdo publicados podem ser inspecionados por qualquer visitante.
- Sessões, fichas e preferências ficam somente no navegador.
- O perfil Mestre é uma demonstração da interface, não uma conta administrativa segura.
- Nenhum dado real ou privado deve ser colocado neste build.

Autenticação real exige backend, armazenamento seguro de credenciais, autorização por resposta e remoção dos dados classificados do pacote público.
