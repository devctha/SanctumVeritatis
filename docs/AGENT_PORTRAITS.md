# Retratos de agentes

- Formatos: PNG, JPG/JPEG e WebP.
- Limite: 5 MB; resolução mínima 300×300.
- Recorte institucional 3:4, zoom, rotação, espelhamento e oito filtros.
- Saída processada em WebP: retrato 600×800 e miniatura 180×240.
- Original, versão completa e miniatura ficam no IndexedDB `sv-agent-media`.
- O perfil armazena somente IDs e data de atualização.
- Chaves são derivadas do agente; imagens não são compartilhadas.
- A imagem não sai do navegador. Limpar os dados do navegador pode removê-la.
