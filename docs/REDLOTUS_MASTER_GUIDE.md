# Guia do Mestre — RedLotus

No painel do Mestre, abra `Controle narrativo`.

Para cada agente é possível:

- conferir e avançar Sintech;
- conceder pista ou resetar progresso;
- ativar marca RedLotus;
- abrir Jardim ou Raiz;
- resetar progresso RedLotus.

Todas as alterações são locais ao navegador atual.
