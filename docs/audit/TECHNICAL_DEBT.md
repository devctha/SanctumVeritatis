# Dívida técnica consolidada

## Crítica

- conteúdo privado no mesmo frontend público;
- ausência de backend e autorização por recurso;
- acesso Mestre local sem autenticação forte.

## Alta

- páginas legadas monolíticas com CSS/JS inline;
- assets grandes e sem inventário completo de licença;
- cobertura de navegador limitada às rotas modernizadas;
- nomes/rotas históricas inconsistentes e aliases duplicados.

## Média

- falta de repositório unificado para operações, agentes e documentos;
- estados administrativos somente no armazenamento local;
- 30 reservas S.A.L.A. vazias;
- ausência de métricas Lighthouse e testes com leitor de tela.

## Baixa

- padronização progressiva de formatador e CSS;
- preview de múltiplos formatos documentais;
- paginação/virtualização somente se o uso real justificar.

A dívida deve ser reduzida módulo a módulo. Uma migração global de framework ou diretórios não é recomendada enquanto GitHub Pages e URLs legadas forem requisitos.
