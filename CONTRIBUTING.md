# Contribuindo

Crie uma branch a partir da principal, preserve conteúdo narrativo e URLs e mantenha segredos fora do repositório. Execute `npm.cmd run validate` antes de abrir um pull request. Mudanças de dados gerados devem alterar a fonte e executar o gerador correspondente; não edite somente o artefato gerado. Registre incompatibilidades e migrações em `docs/REBUILD_REPORT.md`.
