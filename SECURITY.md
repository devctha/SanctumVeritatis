# Política de segurança

## Relato responsável

Não publique vulnerabilidades, credenciais, dados pessoais ou spoilers em issues. Use o canal privado de contato do proprietário do repositório. Se uma credencial real tiver sido commitada, considere-a comprometida e revogue-a antes de qualquer limpeza histórica.

## Limites atuais

Este projeto é um site público e estático. Credenciais, papéis e bloqueios executados no navegador são recursos narrativos e não constituem autenticação, autorização ou confidencialidade. Qualquer pessoa pode baixar HTML, JavaScript e JSON publicados.

Não armazene tokens, respostas secretas, notas privadas do mestre ou dados pessoais em `data/`, JavaScript, HTML, commits, Actions ou GitHub Pages. Para confidencialidade real, use um backend que autentique o usuário e filtre cada resposta no servidor.

## Versões suportadas

Somente a versão atualmente publicada a partir de `main` recebe correções. Não há release estável versionada neste momento.

## Resposta

Relatos confirmados devem resultar em contenção, rotação de qualquer segredo, correção testada e documentação. Reescrita de histórico remoto exige planejamento e autorização explícita.
