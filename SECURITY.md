# Segurança

Não reporte vulnerabilidades em issues públicas. Compartilhe o relato de forma privada com o mantenedor do repositório.

Este projeto é atualmente um site estático. Credenciais, papéis e bloqueios no navegador são recursos narrativos e não constituem segurança de servidor. Não armazene informações privadas, tokens ou segredos reais em `data/`, JavaScript, HTML, commits ou GitHub Pages. Para confidencialidade real, migre autenticação, autorização e dados classificados para um backend que filtre cada resposta no servidor.
